Fanowskie spolszczenie do gry Hytale które może zawierać błędy.
Będę starał się aktualizować na bierząco. Gdyby były jakieś błędy proszę o mówienie mi o nich abym mógł nanieść poprawki.

Zawiera instalator aby nie musieć instalować tego ręcznie podmieniając pliki. 
Instrukcja użycia instalatora jest w środku.

Ręczna instalacja spolszczenia czyli podmiana plików:
Aby zainstalować, przejdź do folderu głównego gry. Jeśli nie wiesz, gdzie się znajduje, otwórz program uruchamiający > Ustawienia (ikona koła zębatego) > „Otwórz katalog”.
Główny folder zawsze znajduje się w katalogu takim jak ten "C:\Users\YourName\AppData\Roaming\Hytale\install\release\package\game\latest\Client\Data\Shared"
Wejdź do zip i znajdź 2 foldery "Fonts" oraz "Language" i przerzuć je do Shared
To wszystko możesz włączyć gre i ustawić Polski jako język gry.
